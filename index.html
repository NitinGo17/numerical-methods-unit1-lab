What to watch for: in Bisection the bracket halves every time, so the answer improves at a fixed rate. In False Position the chord is drawn from the two endpoints and lands much closer to the root — but notice how one endpoint can stay stuck for every iteration. In Newton–Raphson there is no bracket at all; the tangent line's own x-intercept becomes the next guess, which is why it can jump straight onto the root in three or four steps.

02

Why Newton wins — rate of convergence

error vs iteration, log scale
Bisection False Position Newton–Raphson

The bisection line looks jagged rather than straight — that is not a plotting error. Its midpoint can land on either side of the root, so any single estimate may be worse than the one before it. What halves reliably is the bracket width, not the error of one estimate.

Each line is the true error |xn − r| after every iteration, plotted on a log scale for the equation selected above. A straight line means the error is being multiplied by a constant each step — linear convergence. A line that plunges steeply and then runs out of digits means the number of correct decimals is roughly doubling — quadratic convergence.

rate of convergence of Newton's method if en = xn − r, then   en+1 ≈ ( f″(r) / 2f′(r) ) · en2
so   |en+1| ≤ ( M / 2m ) · en2   where M = max|f″|, m = min|f′| on the interval
Order, not speed. Bisection has order 1 with rate ½ — you gain one binary digit per step, so about 3.3 steps per decimal place. Newton has order 2 — roughly double the correct decimals each step. False Position is normally order 1 and can be slower than it looks when one endpoint stagnates.

The three methods side by side

what to write in the exam
Method 1

Bisection

Halve a sign-changing interval, keep the half that still changes sign. Needs nothing but continuity.

Formula
c = (a + b) / 2
Needs
f(a)·f(b) < 0
Speed
slow, always works
Order
1 (rate ½)
Stopping
|b − a| < ε
Method 2

False Position (Regula Falsi)

Same bracket, but take the chord's x-intercept instead of the midpoint — uses the function values, so it usually lands nearer the root.

Formula
c = [a f(b) − b f(a)] / [f(b) − f(a)]
Needs
f(a)·f(b) < 0
Speed
usually faster than bisection
Order
1, can stagnate
Stopping
|f(c)| < ε
Method 3

Newton–Raphson

Follow the tangent at the current guess down to the x-axis. No bracket needed, fastest of the three — if it converges.

Formula
xn+1 = xn − f(xn)/f′(xn)
Needs
f′ ≠ 0, a good start
Speed
fastest
Order
2 (quadratic)
Stopping
|xn+1 − xn| < ε
04

Marks lost on this unit, every year

check before you close the paper
  • Starting without checking the bracket. Always show f(a)·f(b) < 0 first.without it, the whole answer is unsupported
  • Updating the wrong endpoint — replace the one whose sign matches f(c).bisection and false position both
  • Swapping the numerator in the Regula Falsi formula: a pairs with f(b).c = [a·f(b) − b·f(a)] / [f(b) − f(a)]
  • Using Newton without differentiating correctly, or starting where f′ ≈ 0.f′(x) = 0 makes the next step undefined
  • Reporting more decimals than the iterations earned.state the stopping condition you used
  • Writing only a table with no substitution. Show one full worked substitution per method.that is where the method marks sit
