# Numerical Methods - Unit I Visual Lab

An interactive, single-page visual lab for Unit I: Roots of Equations (Numerical Methods).
Everything is driven by live controls in the browser - no build step, no install, no backend.

## What's inside

- Bisection, Regula Falsi (false position), Newton-Raphson, Secant and Fixed-Point iteration
- Live plot of the function with the iteration path drawn on it
- Convergence tables generated as you change inputs
- Worked examples alongside each method

## Run it

Open the published site below, or download `index.html` and open it in any modern browser.
Everything runs client-side; the only external request is the Google Fonts stylesheet.
